Welcome to my site. This first post is a placeholder so the blog has something
to show.

## Built with

This site is made with **Astro**, **React** (for interactive bits) and
**Tailwind CSS**, deployed to GitHub Pages.

## Writing posts

Add a Markdown file to `src/content/blog/` with `title`, `description` and
`date` in the frontmatter. Set `draft: true` to hide a post from the site.
