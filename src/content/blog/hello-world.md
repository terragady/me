Hi — I'm Marcin, a senior full-stack developer based in Oslo. After a PhD and a
few years in research, I moved into software and have spent the last several
years shipping web and mobile products, currently in financial services at
Storebrand.

This site is where I'll collect my work and the occasional note on things I'm
learning — lately a lot of that is around agentic coding workflows and building
with LLMs.

## Built with

Astro, React and Tailwind CSS, deployed to GitHub Pages on a custom domain.
Fast, static, and easy to update.

## Writing posts

Add a Markdown file to `src/content/blog/` with `title`, `description` and
`date` in the frontmatter. Set `draft: true` to keep a post hidden.
