# michalik.no

Personal website of Marcin Michalik — [michalik.no](https://michalik.no)

Static one-pager built with [Astro](https://astro.build), React and Tailwind CSS,
deployed to GitHub Pages.

## Development

```sh
npm install     # install dependencies
npm run dev     # local dev server at http://localhost:4321
npm run build   # production build to ./dist/
npm run preview # serve the built site locally
```

## Deployment

Pushing to `master` builds and deploys to GitHub Pages automatically.
